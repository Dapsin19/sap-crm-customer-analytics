# ABAP Customer Analysis Component

This folder contains an ABAP Objects-style customer analysis demonstration created as part of the SAP CRM Customer Analytics portfolio project.

## Purpose

The ABAP report demonstrates how customer records could be classified into CRM segments based on:

- Customer revenue
- Purchase frequency
- Recency
- Customer value

## ABAP Concepts Demonstrated

- ABAP report structure
- ABAP Objects
- Local classes
- Public methods
- Importing parameters
- Returning parameters
- Structured types
- Conditional business logic
- Customer reporting

## Important Note

This is a learning and portfolio implementation.

It was not developed or executed against a production SAP CRM/SAP S/4HANA system. The purpose is to demonstrate familiarity with ABAP Objects concepts and how ABAP logic could support CRM customer-analysis workflows.
